# Routes

Use this record shape for each route:

```yaml
name: Example destination
canonical_url: https://example.com/
route_type: official-page | public-api | rss | atom | sitemap | export
status: verified | stale | blocked | retired
last_checked: YYYY-MM-DD
permission_note: Public route; obey terms, robots, rate limits, and attribution.
```

A route is not a license to defeat a challenge, bypass authentication, circumvent a paywall, or conceal automated activity. When the direct route is unavailable, explain the limitation and offer a legitimate alternative.
