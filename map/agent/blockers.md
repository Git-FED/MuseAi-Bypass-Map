# Blockers

Blockers describe why a route may be unavailable; they are not a checklist for defeating controls.

| Blocker | Safe response |
|---|---|
| Login wall | Ask the user to sign in or use an official authenticated API. |
| Paywall | Link the publisher, offer a library/licensed source, or summarize permitted public material. |
| Bot check / challenge | Do not automate around it; use an official API or user-controlled browser session. |
| Rate limit | Slow down, cache responsibly, request access, or use a documented feed. |
| Robots restriction | Respect it and choose a permitted source. |
| Geographic restriction | Explain the restriction; do not help evade it. |
| Financial or sensitive institution | Use official channels and heightened privacy safeguards. |
