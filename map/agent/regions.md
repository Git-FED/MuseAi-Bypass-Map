# Regions

## Social
Public profiles, posts, feeds, and documented APIs. Do not scrape private accounts or evade rate limits.

## News
Publisher pages, RSS/Atom feeds, public archives, and licensed syndication.

## Video
Official pages, embeds, captions, channel feeds, and documented APIs.

## Shopping
Merchant catalogs, product pages, feeds, and structured data made public by the seller.

## Docs
Documentation sites, sitemaps, static exports, and release notes.

## Code
Public repositories, package registries, release pages, and issue trackers.

## Music
Artist pages, labels, catalogs, release feeds, and public metadata.

## Forums
Public threads, feeds, and official search endpoints.
