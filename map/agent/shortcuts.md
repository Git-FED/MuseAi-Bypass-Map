# Shortcuts

Shortcuts are direct content endpoints that reduce page chrome without evading controls.

- RSS/Atom feeds published by the destination
- JSON or GraphQL endpoints documented by the destination
- Sitemaps and static documentation indexes
- Official embed URLs
- Public release feeds and package metadata
- Licensed text, accessibility, or print views

Every shortcut needs a source URL, a freshness date, and a note explaining why its use is permitted. Never guess undocumented endpoints or use a shortcut to avoid access controls.
