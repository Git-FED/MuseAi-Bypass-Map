# Human Map

The human map is a visual index for exploring the internet by territory rather than by search-result rank. Open `index.html` locally; it is a single dependency-free file.

Pins represent destination categories, not guarantees of availability. A pin's detail card shows the intended route type and safety note. Colors distinguish social, news, video, shopping, docs, code, music, and forums.

Pan, zoom, and select pins. The animated background is decorative and generated in the browser with Canvas; no image or network request is needed.
