MUSE / ATLAS 01

A living map for the content layer.

The visual map is a dependency-free static HTML experience designed to work from GitHub Pages, Cloudflare Pages, or a local folder.

What makes it fun

Animated terrain

Canvas waves, star dust, glowing route corridors, and pulsing destination pins.

Small comic energy

Promotional banners, badges, GIFs, and playful route copy make the atlas feel alive.

Static-friendly

No server, database, package install, or external font is required. Every page is ordinary HTML.

Deployment note

For GitHub Pages or Cloudflare Pages, publish the project root as a static directory. The HTML links use relative paths, so they remain portable under a project subpath.
