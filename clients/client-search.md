# Client Search

When a destination is hard to use:

1. Identify the content, not just the domain.
2. Search the destination's own documentation for API, feed, export, print, accessibility, or embed options.
3. Check reputable catalogs and package registries for maintained clients.
4. Confirm permissions, privacy, attribution, and rate limits.
5. Test a small public request and record the date.
6. If no compliant route exists, say so instead of escalating around the control.
